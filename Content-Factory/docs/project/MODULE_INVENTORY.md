# MODULE INVENTORY

## Инвентарь модулей и фактических ролей

## `bulk-text-cleaner`
- **Роль:** массовая техническая очистка текстов перед дальнейшей обработкой.
- **Ключевые скрипты:** `clean_stories.py`, `clean_stories_gui.py`.
- **Вход:** каталог историй с сырыми `.txt`.
- **Выход:** очищенные и нормализованные тексты.
- **Внешние зависимости:** Python stdlib + GUI (`tkinter`).
- **Side effects:** перезапись/переименование файлов.
- **Риск интеграции:** средний (destructive file ops).
- **Трогать внутри на 1 этапе:** нет.

## `Gemini_Auto`
- **Роль:** автоматическая генерация metadata/`info.txt` и отчетов.
- **Ключевые скрипты:** `gemini_auto.py`.
- **Вход:** story-папки с текстами.
- **Выход:** `info.txt`, отчеты по обработке.
- **Внешние зависимости:** Playwright/Chrome-профиль, Gemini web-flow.
- **Side effects:** запись файлов в story-папки, зависимость от браузерной сессии.
- **Риск интеграции:** высокий (web automation + квоты + сессии).
- **Трогать внутри на 1 этапе:** нет.

## `Отбор для YouTube`
- **Роль:** качественный фильтр историй для YouTube (проходит/не проходит).
- **Ключевые скрипты:** `gemini_auto.py`, `build_otbor.py`.
- **Вход:** пул историй для оценки.
- **Выход:** разделение на пригодные/непригодные, служебные отчеты.
- **Внешние зависимости:** Gemini web-flow, параллельные профили.
- **Side effects:** move в `trash`, claim-файлы для worker-параллелизма.
- **Риск интеграции:** высокий (параллельность + переносы).
- **Трогать внутри на 1 этапе:** нет.

## `Озвучка для YouTube`
- **Роль:** safe-переработка текста и подготовка audio-ready версии под YouTube.
- **Ключевые скрипты:** `gemini_auto.py`, `promo_inserter.py`, `delete_clean_outputs.py`.
- **Вход:** отобранные истории.
- **Выход:** safe-тексты, подготовленные файлы под озвучку, promo-вставки.
- **Внешние зависимости:** Gemini web-flow.
- **Side effects:** создание/удаление промежуточных файлов.
- **Риск интеграции:** высокий (safety-трансформации + возможные delete-операции).
- **Трогать внутри на 1 этапе:** нет.

## `Режиссер 2.0`
- **Роль:** визуальная режиссура и генерация кадров.
- **Ключевые скрипты:** `main.py`, `gemini_characters.py`, `gemini_director.py`, `comfyui_factory.py`, `characters_payload.py`.
- **Вход:** очищенный/подготовленный story-text.
- **Выход:** `characters.txt`, `prompts_list.txt`, `frames/*`.
- **Внешние зависимости:** Gemini, ComfyUI/RunPod API.
- **Side effects:** массовая генерация файлов кадров, сетевые вызовы.
- **Риск интеграции:** высокий (дорогие внешние вызовы, ретраи, квоты).
- **Трогать внутри на 1 этапе:** нет.

## `ElevenLabs`
- **Роль:** генерация озвучки и lifecycle API-ключей.
- **Ключевые скрипты:** `main.py`, `audio_processor.py`, `account_manager.py`, `state_manager.py`, `text_chunker.py`, `audit_keys.py`.
- **Вход:** подготовленные тексты + voice-маркировка (`M/F/U`).
- **Выход:** готовые аудио-файлы + state/log.
- **Внешние зависимости:** ElevenLabs API, иногда прокси/VPN-обвязка.
- **Side effects:** запись аудио, изменение key/state файлов.
- **Риск интеграции:** высокий (квоты/ключи/сетевая нестабильность).
- **Трогать внутри на 1 этапе:** нет.

## `AutoVideo`
- **Роль:** сборка финального видео из аудио и изображений.
- **Ключевые скрипты:** `main.py`.
- **Вход:** `audio.mp3` + `images/*` (+ опциональные overlay).
- **Выход:** финальный `mp4`.
- **Внешние зависимости:** `ffmpeg`, `ffprobe`.
- **Side effects:** большие временные файлы, cleanup.
- **Риск интеграции:** средний (длительные batch-процессы).
- **Трогать внутри на 1 этапе:** нет.

## `content_combiner`
- **Роль:** сборка/упаковка артефактов перед публикацией.
- **Ключевые скрипты:** `content_combiner.py`.
- **Вход:** тексты/аудио/изображения и служебные поля.
- **Выход:** собранные story-папки + экспортные таблицы (`csv`).
- **Внешние зависимости:** файловая структура проекта.
- **Side effects:** move/rename/copy.
- **Риск интеграции:** средний.
- **Трогать внутри на 1 этапе:** нет.

## `autopublisher`
- **Роль:** финальная доставка контента в облако и БД.
- **Ключевые скрипты:** `publish_stories.py`, `check_r2_status.py`, `cleanup_r2_orphans.py`.
- **Вход:** подготовленные story-папки для публикации.
- **Выход:** файлы в R2, записи в Supabase, архив публикаций.
- **Внешние зависимости:** S3-compatible API (R2), Supabase.
- **Side effects:** внешние write-операции + перемещения локальных папок.
- **Риск интеграции:** высокий (прод-данные, необратимые публикации).
- **Трогать внутри на 1 этапе:** нет.

## Cross-cutting наблюдения
- Модули связаны в основном через файловую систему, а не через API-контракты.
- Есть дублирование логики между похожими ветками.
- На первом цикле нужна обвязка-контракт, а не изменение бизнес-логики модулей.
